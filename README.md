# Adeyemo Benjamin Ajala — Football Profile

This folder contains the website homepage (`index.html`) for the player profile.

## Upload to GitHub
1. In your repository, choose **Add file → Upload files**.
2. Upload `index.html` and `README.md` from this folder.
3. Click **Commit changes**.

## Important after publishing
In `index.html`, replace `YOUR-GITHUB-USERNAME` in the canonical link with your actual GitHub username. The website address for a project site will usually be:
`https://YOUR-GITHUB-USERNAME.github.io/adeyemo-benjamin-ajala/`

The goals and minutes shown are combined totals supplied by the player and are not independently verified.
